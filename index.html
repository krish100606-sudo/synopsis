Project Title & Summary

AI-DRIVEN HEALTH AND FITNESS TRACKER

A cloud-ready, microservices-based platform built on Spring Boot that converts raw physical activity data into personalized coaching insights. Integrates Google's Gemini API for structured fitness recommendations and RabbitMQ for asynchronous non-blocking processing.

Project Objectives & Features

  • Microservices Backend: Separates user management, activity logging, and AI recommendation microservices.
  • Asynchronous RabbitMQ Queue: Prevents heavy AI LLM processing from blocking user UI response times.
  • Google Gemini API: Automatically generates personalized fitness insights, safety warnings, and recovery recommendations.
  • Keycloak Security: Implements standard OAuth 2.0 PKCE authentication flow.
